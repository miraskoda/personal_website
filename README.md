# Miroslav Škoda — Portfolio

Personal portfolio site: Senior Flutter Developer, experience, education, certifications, and contact.

## Tech

- Vanilla **HTML**, **CSS**, and **JavaScript**
- No build step or dependencies
- Fonts: Space Grotesk, DM Sans, JetBrains Mono (Google Fonts)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
# Python
python3 -m http.server 8000

# Node (npx)
npx serve .
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — single-page layout, inline styles and scripts
- `favicon.ico` — site favicon
